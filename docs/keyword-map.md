## 11. 与竞品对比的初步 Gap 假设（待 STEP 9–11 Firecrawl 验证）

- **Port 对比数据**：Jeddah vs Dammam 怎么选（竞品普遍只写单港）
- **Hidden Costs**：demurrage / detention / origin charges 拆解
- **Duty + VAT 计算**：Saudi 15% VAT、UAE 5% VAT 的落地算法
- **合规门槛**：SASO/SABER、进口许可证、HS code
- **中文网实操经验**：义乌/广州小商品出货、DDP 双清包税的实际操作
- **数据方法论公开**：运价如何估算、来源、假设（Trust Gap）
